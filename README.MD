# いばらにうむ

インフラの保守運用と、仕様書作成・要件定義などの上流工程を経験した元システムエンジニアです。
現在は趣味の範囲で、音声合成や Web ツールを作っています。

## 💼 Career

**2022〜現在｜個人開発**
音声合成、Web ツール（Cloudflare）、デスクトップアプリなどを制作。

**2020〜2022｜システムエンジニア（SES / 正社員）**

- **大手金融機関｜サーバー保守・運用（1年6か月 / チームリーダー・4名）**
  各種サーバーの保守・監視・運用（二次対応）を担当。報告されたトラブルのリスト対応、Swift によるサーバーサイド処理の改修、スクリプトによる運用の自動化・効率化、定期メンテナンス時の再起動・ログ監視・バックアップ管理。
- **印刷機器メーカー｜要件定義・基本設計（3か月）**
  新規プリンターの機能仕様書・インターフェース仕様書の作成。クライアントと開発チームへのヒアリング・調整、実機での機能検証、既存製品との機能差分分析と仕様書への反映。

**経験工程：** 要件定義 / 基本設計 / 機能検証 / 保守・運用・監視
